Open Source Metro

The GitHub-style 53-week by 7-day contribution grid is the foundation. Metro services weave through actual recorded days; repository stations are indexed below. The supplied fixture is intentionally sparse. Empty days are not evidence of zero GitHub contributions.

Swipe sideways to inspect the complete 53-week map. The map scrolls inside this panel, not across the whole page.

Illustration from the shared synthetic fixture, not the owner's actual GitHub contributions.

All alternative palettes can be generated locally with Python 3.11+. The included README SVGs work without any setup.

The grid is the canvas

53 Sunday-to-Saturday columns, weekdays, month labels and observed-event density. No fabricated history.

Transit routes are factual

Five event-type services call only at dated source events. Trains, when enabled, traverse those routes.

Stations are real identifiers

Named repositories, exact event IDs and UTC dates are disclosed in calendar-cell tooltips and accessible labels.

No token, external API, JavaScript library, external fonts or paid service required. Animated SVG playback in GitHub README previews is not guaranteed.
